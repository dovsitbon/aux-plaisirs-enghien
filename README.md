# Aux Plaisirs d'Enghien

Site vitrine du restaurant chinois & vietnamien **Aux Plaisirs d'Enghien**, 5 Rue Gaston Israël, 95880 Enghien-les-Bains.

Next.js (App Router) · Tailwind CSS v4 · Lucide React.

```bash
npm install
npm run dev
```

- Données du restaurant (carte, horaires, avis, photos) : `src/lib/restaurant.ts`
- Les photos sont des visuels Unsplash d'illustration, à remplacer par de vraies photos du restaurant.
